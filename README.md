# Escala - protótipo em HTML e CSS

Protótipo da plataforma de troca de plantões médicos (DSW2), feito só com HTML e CSS.

Para abrir, basta abrir o `index.html` no navegador. Não precisa instalar nada.

## Páginas

| Arquivo | Página |
|---|---|
| `index.html` | Lista de plantões com busca e filtros |
| `plantao.html` | Detalhe de um plantão e candidatura |
| `publicar.html` | Formulário para publicar um plantão |
| `meus-plantoes.html` | Plantões publicados e assumidos |

## Organização

- `css/style.css`: estilo de todas as páginas
- `favicon.svg`: ícone da aba
